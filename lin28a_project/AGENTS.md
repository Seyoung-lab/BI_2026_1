# AGENTS.md

## Project rule

This repository contains guided mission files and a LIN28A final project.

All new analysis files must be created under:

`lin28a_project/`

Do not modify existing guided mission notebooks or files in the repository root unless explicitly instructed.

## Protected input data

The following directory contains input data and must be treated as read-only:

`tools/binfo1-datapack1/`

Do not modify, move, rename, delete, or overwrite files in this directory.

BAM/BAI/pileup/bedgraph files must not be copied into `lin28a_project/` unless explicitly requested.

## Git rules

Before making changes:
1. Run `git status`.
2. Summarize the current state.

After making changes:
1. Run `git status`.
2. Summarize changed/created files.
3. Provide a short git-diff-style summary.

Do not run `git add`, `git commit`, or `git push` unless explicitly asked.

## Data rules

Large files should not be tracked by git:
- `.bam`
- `.bai`
- `.sam`
- `.fastq`
- `.fq`
- `.pileup`
- `.bedgraph`
- `.bw`
- `.bigWig`

Use `tools/binfo1-datapack1/` as read-only aligned read-level input.

Use `lin28a_project/data/supplementary_tables/` for downloaded supplementary tables.

Use `lin28a_project/data/processed/` only for small processed CSV/TSV files generated by this project.

## Analysis rules

Do not choose biological thresholds silently.

For every threshold, report:
1. the column used,
2. the proposed cutoff,
3. the number of genes/transcripts selected,
4. a short justification.

When possible, test more than one candidate threshold.

Do not generate excessive plots. For each step, make only the plots requested in the current spec.

## Output rules

Save figures to:

`lin28a_project/results/figures/`

Save tables to:

`lin28a_project/results/tables/`

Save notes and data dictionaries to:

`lin28a_project/notes/`

Use clear filenames with step numbers.
